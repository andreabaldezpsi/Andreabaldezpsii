# Site — Psicóloga e Neuropsicóloga Andréa Baldez

Site responsivo para GitHub Pages.

## WhatsApp
Todos os botões de agendamento abrem o WhatsApp **(21) 96571-8806** com esta mensagem pré-preenchida:
> Olá, Andréa! Gostaria de saber mais sobre o atendimento psicológico online e verificar horários disponíveis para marcar uma sessão. Poderia me passar as informações, por favor?

A mensagem aparece na conversa e a pessoa ainda precisa tocar em **Enviar** no WhatsApp.

## Google Meet
O botão Google Meet abre https://meet.google.com/. Ele não cria uma reunião privada automaticamente. Após confirmar o agendamento, Andréa deve criar a reunião e enviar o link específico ao paciente pelo WhatsApp.

## Publicar
1. Envie `index.html`, `styles.css`, `script.js`, `README.md` e a pasta `assets` para o repositório.
2. GitHub → Settings → Pages → Deploy from a branch.
3. Selecione `main` e `/ (root)`, salve e aguarde a publicação.

A seção de formação contém texto para completar com dados acadêmicos confirmados. Não publique qualificações não verificadas.

## Formação profissional
O número de CRP identifica o registro profissional, mas não permite deduzir com segurança as instituições, cursos ou especializações. A seção de formação foi mantida transparente e deve ser completada com informações e comprovantes fornecidos pela profissional.
