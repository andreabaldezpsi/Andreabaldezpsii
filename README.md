O botão Google Meet abre https://meet.google.com/. Ele não cria uma reunião privada automaticamente. Após confirmar o agendamento, Andréa deve criar a reunião e enviar o link específico ao paciente pelo WhatsApp.

## Publicar
1. Envie `index.html`, `styles.css`, `script.js`, `README.md` e a pasta `assets` para o repositório.
2. GitHub → Settings → Pages → Deploy from a branch.
3. Selecione `main` e `/ (root)`, salve e aguarde a publicação.

A seção de formação contém texto para completar com dados acadêmicos confirmados. Não publique qualificações não verificadas.
