## Publicação no GitHub Pages
Este projeto é estático: não usa servidor Node.js, banco de dados, vídeo, áudio ou integrações de videoconferência.

1. Crie um repositório no GitHub.
2. Envie o conteúdo da pasta `public` para a raiz do repositório (index.html, style.css, app.js, favicon.png e favicon.ico).
3. No repositório, abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch, escolha `main` e `/ (root)`, e salve.
5. Aguarde a publicação e abra o endereço exibido pelo GitHub Pages.

O favicon está referenciado com caminhos relativos para funcionar também em repositórios GitHub Pages.

## Arquivos

- `public/app.js`: menu móvel e ano do rodapé.
